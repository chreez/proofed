## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
## Design Notes
- User chose **Timeline (Hybrid)** variant as the direction
- Brand dot alignment: timeline spine dots should align with the header "proofed." dot on desktop — this only works at wider viewports since header (`max-w-4xl`) and content (`max-w-3xl`) have different max-widths. Mobile will diverge. Pin for future polish.
- Sort: alphabetical (not bake-count-desc)
- No welcome section needed — header already has brand

- **Main `py-6` padding**: The `<main>` element in App.vue has `py-6` which adds top padding above the timeline. Can't hack around it cleanly — needs proper layout restructuring in PF-97 implementation (e.g. per-route padding control or moving padding into individual page components).

## Recipe Summary Metadata (spike needed)
- Some recipes have `meta.description` (pizza, carrot cake, thai tea, coco curry, tsukemen) but not all
- No description field in `index.json` — would need to either: (a) add descriptions to all recipes + fetch each JSON for it, or (b) add a `description` field to index.json entries for lightweight access
- Spike needed: decide schema approach + write missing descriptions

## Mobile UX Decision
- Current: tap to expand (explicit but clunky)
- Better for mobile: IntersectionObserver scroll-into-view auto-expand (whichever item is centered expands naturally, turns list into a feed)
- Desktop stays hover-driven

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
## Spike Complete: Timeline layout with motion-v

**Chosen direction**: Clean timeline — vertical spine, category grouping, scroll-triggered slide-up + fade via `motion-v`.

**Key decisions**:
- Sort: baked-first, then alphabetical (not bake-count-desc — AC #3 updated)
- Animation: `motion-v` library (`<motion.li>` with `whileInView`, per-item stagger delay, cubic-bezier `[0.22, 1, 0.36, 1]`)
- Mobile: dot-fill on scroll-centered item, hover on desktop
- Hero images: 6rem cropped thumbnails for recipes that have photos
- Category labels: monospace uppercase with bottom border

**AC #3 note**: Original AC said "bake count descending" but user chose alphabetical sort during implementation. AC left unchecked as written — behavior is correct per user direction.

**Feeds into PF-97**: Timeline layout, motion-v animation pattern, category grouping, mobile scroll behavior.
