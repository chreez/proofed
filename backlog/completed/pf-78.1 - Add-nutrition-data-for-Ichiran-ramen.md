## Description

Calculate nutrition data for Ichiran ramen recipe via USDA pipeline (same pattern as PF-70.1 for CoCo curry and PF-71.2 for Thai Tea Boba).

Notable ingredients needing mappings:

- Pork bones/trotters/skin: Conservative extraction estimates (15-30 kcal/100g) — solids discarded after 12h cook
- Dried fish (katsuobushi, kombu): Weighted extraction values based on breakdown proportions (steeped/strained portions at 25% extraction)
- Pork back fat (aroma oil) and pork shoulder (chashu): Full raw values — consumed
