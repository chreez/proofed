## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
FDA nutrition facts label component for printout. Visual style chosen from PF-211.5 demo (exact FDA / proofed-branded / hybrid).

Displays per-serving values with full-recipe totals available. FDA-required line items: calories, total fat, saturated fat, trans fat, cholesterol, sodium, total carbs, dietary fiber, total sugars, added sugars, protein.

Shows "Not yet calculated" placeholder when nutrition data is incomplete. Lower priority than allergens — nutrition pipeline exists.
