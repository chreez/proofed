## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Update the `/bake-log` skill to optionally capture structured stats data (room temps, dough temps, S&F timestamps, aliquot rises, bake phases) and write them to `cook_log[entry].bake_stats`. Verbatim bake log paste also preserved in `raw_notes`.

## Capture rules

- **Cook Log Protocol applies** — scribe only, never infer. If user doesn't mention a field, skip it. Never guess temps, timestamps, or quantities.
- **Non-tedious** — single optional ask per field group, skipped if user has nothing to record. Skill should not pester.
- **Both layers** — structured `bake_stats` AND verbatim `raw_notes` populated, per PF-177.2 demo decision.

## Field groups

Per Option A schema (PF-177.3):

1. `dough_temps[]` — measurements with timestamps
2. `bulk_ambient_temps[]` — array per room-temp day (one entry per day at room temperature during bulk)
3. `bake_phases[]` — preheat / covered / uncovered (each with temp + duration)
4. `stretch_folds[]` — timestamps + type
5. `aliquot_rises[]` — timestamps + rise %

Each group is one optional prompt during the clarify loop.

## Validation

Next bake after this lands uses the updated skill end-to-end as the validation.
