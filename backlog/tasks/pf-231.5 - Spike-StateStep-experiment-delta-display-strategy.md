## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Research the least fragile way to show experiment adjustments on StateStep components.

Current approach (fuzzy name match + inline value replacement) breaks on:
- Range formats (675-700g)
- Partial amounts (675g, holding back 25g)
- Name mismatches between components and ingredients

Options to evaluate:
1. Banner above components — single accent-bordered line listing adjusted ingredients + deltas
2. Component-level badges — fix matching with ID-based lookup instead of name heuristic
3. Subtle inline note — muted text below components
4. Hybrid — annotate matched components, show banner for unmatched

Evaluation criteria: breakage surface area, visual noise, implementation complexity, scaling composition.

Deliverable: Recommended approach with rationale, edge cases, draft tasks.
