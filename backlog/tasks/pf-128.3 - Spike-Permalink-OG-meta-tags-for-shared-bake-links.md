## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Research and prototype OG meta tags (Open Graph) for shared bake detail URLs so they preview nicely when pasted in iMessage, WhatsApp, social media, etc. This is an alternative/complement to QR code labels — permalink sharing is the primary share path.

Investigate:
- Dynamic OG meta tags for SPA (Netlify edge functions? prerender?)
- og:title, og:description, og:image for bake detail pages
- What the preview card looks like in iMessage, WhatsApp, Slack
- Whether Netlify supports per-route meta without SSR
<!-- SECTION:DESCRIPTION:END -->
