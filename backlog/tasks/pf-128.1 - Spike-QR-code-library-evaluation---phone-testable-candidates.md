## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
## Spike Result\n\nUser tested all 3 libraries on iPhone. **`qr-code-styling` wins.**\n\n| Library | Size | Output | User Verdict |\n|---------|------|--------|--------------|\n| `qrcode` | ~30KB | Canvas | Functional but basic |\n| `qr-code-styling` | ~50KB | Canvas | **Winner** — best styling, brand-matchable |\n| `uqr` | ~1.5KB | SVG | Not saveable on mobile Safari |\n\n**Why qr-code-styling**: Rounded dots, styled corners (accent #a65d45), logo embedding support. The richer visual treatment matters for a QR that goes on physical labels.\n\n**License**: MIT (free)\n\n**Gotchas**: Uses DOM-append API (not Vue-idiomatic — pass container, it appends canvas). Largest bundle but acceptable for a personal app with one QR per share page."
