## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
BSM Heritage Bundle (heritage-bundle-certified-organic) is a single $43 SKU containing 4 component flours (e.g., Rouge de Bordeaux, etc.). User reported using a bundle-derived flour in their last bake — v1 of PF-275 excludes bundles to ship faster.

Research + design:
- How to model a bundle in the cost system: bundle product + component map
- Allocation strategy: equal split, by weight, by user-entered fraction, or by amount used per bake?
- Where the bundle-component map lives: hardcoded JSON, BSM body_html parsing, or manual UI entry?
- Schema impact on CostSelection / CostLineItem
- Picker UX when a flour ingredient could be priced from either a single-product or a bundle

Output: decision doc + schema proposal + UX sketch. Create follow-up implementation task(s).
