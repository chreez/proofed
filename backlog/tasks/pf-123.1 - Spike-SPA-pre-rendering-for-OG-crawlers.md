Research how to make OG meta tags visible to non-JS crawlers in a Vite + Vue SPA deployed on Netlify. The user has solved this before in two other projects.

- `~/workspace/vyra` — check for pre-rendering, edge functions, or SSR approach

3. Can we inject per-recipe OG tags at build time from the recipe JSON files (they're static and available at build)?
4. If edge function: how to read recipe JSON + resolve hero image path at the edge?

## Spike Findings — 2026-02-11

**Vyra:** Netlify edge function with User-Agent sniffing — overkill for static data
**Deadlock Fight Club:** Build-time script generates per-route index.html — same pattern proofed. already uses
**proofed.:** `scripts/prerender-og.ts` already exists and runs in build pipeline. Only gap: og:image hardcoded to generic card.

**Recommendation:** Extend existing script. Add `resolveHeroImage()` that reads `cook_log[0].photos[last].src`. Fallback to `og-image.png` for recipes without photos.

**WebP note:** 800w WebP should work for most crawlers (Discord, Slack, iMessage). Test iMessage first before adding JPEG fallback.
