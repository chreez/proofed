## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Implemented timer alerts with three independent channels:

**Audio alert** (`useTimerAlerts.ts`): Web Audio API generates a two-tone sine wave (C5 + E5) on timer completion. Audio context is unlocked on first Start button click (iOS Safari user gesture requirement). Wrapped in try/catch -- failure logs a warning, doesn't crash.

**Web Notification API** (`useTimerAlerts.ts`): Permission requested on first timer start. On completion, fires a notification with timer title and duration. Silently skips if notifications are blocked or unavailable.

**iOS Clock deep link** (`TimerDisplay.vue`): "Set iOS Timer" button uses `clock-timer://` URL scheme to open iOS Clock Timer tab. Only rendered when `isIOS()` returns true (detects iPhone/iPad via user agent + touch points heuristic).

**Integration**: `useTimer.ts` extended with `onStart` and `onComplete` callbacks via a new options object (backward-compatible with the old number signature). `TimerDisplay.vue` wires `handleStart` (unlocks audio + requests notification permission) and `handleComplete` (plays sound + fires notification) into these callbacks. Each channel has independent try/catch -- one failing cannot block others.

**Files changed:**
- `src/composables/useTimerAlerts.ts` (new) -- audio, notification, iOS detection utilities
- `src/composables/useTimerAlerts.spec.ts` (new) -- 14 tests covering all utilities
- `src/composables/useTimer.ts` -- added `UseTimerOptions` interface with `onStart`/`onComplete` callbacks
- `src/components/TimerDisplay.vue` -- integrated alerts, added iOS timer button to both compact and full layouts
- `src/components/StateStep.vue` -- passes `timerTitle` prop to TimerDisplay
