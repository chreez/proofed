## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Demo spike showing 2-3 visual/UX variants for the bake scratchpad system. Present side-by-side on a throwaway demo page for user review.

**Variants to explore:**
1. **Note UI placement:** FAB toolbar (like TOC) vs inline per-step button vs hybrid
2. **Reminder UX:** Icon badge on completed step vs floating banner vs toast notification
3. **Data capture:** Structured form (input/output/result fields) vs freeform with prompts vs hybrid
4. **Connection to feedback flow:** How does the JSON blob integrate with /feedback skill?

**Deliverable:** Demo page at `/demo/scratchpad` with clickable variants. User picks direction, informs parent task implementation.

## Design Decisions (2026-02-14)

- **Placement: B (inline per-step)** — small icon next to each step
- **Reminder UX: B (banner)** — but timing needs rethinking. Prompting AFTER marking done is too late. Reminder should appear DURING or BEFORE the step, not post-completion. Explore: show reminder when step becomes active, or as persistent indicator during step.
- **Data capture UI: approved** as-is (structured form with prompted questions)
- **JSON shape: TBD** at implementation — step-keyed objects (B) likely best fit for inline approach
