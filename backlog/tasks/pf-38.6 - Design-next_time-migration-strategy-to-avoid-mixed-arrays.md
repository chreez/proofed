## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Risk from PF-38.1 spike: `(string | object)[]` for next_time is awkward — CookLogSection.vue line 41 does `.map(n => \`- ${n}\`)` which breaks on objects. Options: (a) always use object shape `{ text, source? }`, (b) keep strings and add separate `next_time_sources` map, (c) normalizer function. Needs decision before PF-38.2 implementation.
