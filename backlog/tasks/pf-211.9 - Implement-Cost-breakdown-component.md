## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Simplified cost display on print page. Two numbers: total bake cost + per-serving cost.

Data source: average cost across all bakes on the current **major version** (vX.*). If no bakes exist on the current major version with cost data, cost section does not render at all (no placeholder).

Example: recipe at v3.6.0 → average cost of all cook_log entries where version starts with "v3." and has cost data.

CostBreakdown.vue component already exists but is over-engineered for this use case. Print view needs inline rendering, not the full component.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Composable `getVersionAverageCost(recipe)` returns `{ total: number, perServing: number } | null`
