## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Build `BakeStatsBlock.vue` component that renders the structured `bake_stats` as the locked Variant C visual, and wire it into `CookLogSection.vue`. Also add the `raw_notes` disclosure toggle.

## Variant C structure (locked from PF-177.1 demo)

1. **Tiles row** — `AVG DOUGH (OVER Xh)` + `BULK AMBIENT (OVER N DAYS)`, computed averages from arrays
2. **Bake Phases block** — 4-column grid: STAGE / START TIME / TEMP / DURATION (uppercase stage labels)
3. **Stretch & Folds block** — 4-column grid with date dedupe within day + dotted day-break rule between days
4. **Aliquot Rises block** — 4-column grid with rise bars + date dedupe + dotted day-break

Progressive render — each block only renders when its source array has length > 0 / scalar non-null. Tiles render `—` when source is empty/missing; tile stays visible.

## Insertion point

Wire into `CookLogSection.vue` between summary line (~line 191) and meta row (~line 192). Only render when `entry.bake_stats` is present.

## Raw notes disclosure

`[▸ Show raw notes]` button in meta row when `entry.raw_notes` exists, toggles a `<pre class="font-mono text-xs">` block expansion.

## Reference

The PF-177.2 demo (`src/components/DemoBakeStatsShapes.vue`, route `/demo/bake-stats-shapes`) is the visual reference for the Variant C styling. Reuse the patterns: 4-column grid templates, dotted day-break rule, rise bar with `parseInt(rise.replace(/^~/, ''), 10)` safety, date dedupe within day. Demo file gets deleted after PF-177.5 lands.
