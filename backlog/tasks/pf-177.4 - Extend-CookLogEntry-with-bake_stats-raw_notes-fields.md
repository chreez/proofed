## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Extend `CookLogEntry` to hold the structured `bake_stats` data per the schema from PF-177.3, plus a verbatim `raw_notes` string for the original bake log paste.

## Two layers per entry

- `bake_stats: BakeStatsBlock` — structured/parsed data populated by `/bake-log` skill (PF-177.6) or backfill (PF-177.7)
- `raw_notes: string` — verbatim paste from the bake log session, preserved as-is, expandable in UI (PF-177.5)

Both fields optional to support progressive backfill of existing entries. The three layers (`raw_notes` verbatim → `bake_stats` structured → `notes[]` curated prose) coexist per the locked decision from PF-177.2 demo review.

This is a types + composables landing — still no UI changes (those land in PF-177.5).
