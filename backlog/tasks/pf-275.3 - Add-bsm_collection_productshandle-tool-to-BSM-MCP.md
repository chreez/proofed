## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
PF-275 AC #3 requires fetching products scoped to a Shopify collection (e.g., `all-flours`). BSM MCP currently has `bsm_collection_list` (lists all collections) but no way to fetch a single collection's products.

Add a new tool `bsm_collection_products(handle, limit?)` that calls `https://bartonspringsmill.com/collections/{handle}/products.json` and returns formatted products. Same shape and error handling as `bsm_product_search`.

Dependency for: PF-275 implementation.
Source: PF-275 grooming session 2026-05-19.
