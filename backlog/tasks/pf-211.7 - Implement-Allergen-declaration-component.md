## Description

FDA Big 9 allergen declaration component for printout. Renders "Contains: Wheat, Milk, Eggs." format.

This is LIABILITY-CRITICAL — allergen data must be verified before rendering. Component must NOT render if allergen data is missing or unverified.

Allergen data schema determined by PF-211.2 spike. Display order: FDA canonical (milk, eggs, fish, shellfish, tree nuts, peanuts, wheat, soybeans, sesame).
