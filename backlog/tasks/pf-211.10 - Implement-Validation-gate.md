## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Validation gate for printout rendering. Enforces: no bad data on printout.

Tiered validation:
- CRITICAL (blocks printout): ingredients must match recipe JSON exactly, allergens must be verified
- RECOMMENDED (placeholder if missing): nutrition data, cost data

Goal: printout is only generated when all data is complete. But partial printout with placeholders is acceptable during development.

The printout is a document you hand to someone — allergen accuracy is the liability-critical path.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 - [ ] Per-section validation: each printout section has a completeness check
- [ ] Critical sections (ingredients, allergens): block render if data unverified
- [ ] Recommended sections (nutrition, cost): show "Not yet calculated" placeholder if incomplete
- [ ] Validation composable/utility reusable across printout components
