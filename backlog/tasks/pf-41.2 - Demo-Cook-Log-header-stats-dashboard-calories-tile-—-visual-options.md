Throwaway demo page showing layout options side-by-side for two visual decisions in PF-41:

## Decision A: Cook Log header stats row layout

Render 3+ options for how the aggregate stats row appears inside the Cook Log section heading area. Examples to explore:

- **A1 — Inline hybrid counts**: mono-font line directly under the 'Cook Log' title, dot-separated (`3 sessions · 24 buns · ~96 servings · ~28.8k cal · v1.0 (2x), v1.1 (1x)`). Mirrors StatsPage `ds3-hybrid-counts` pattern.
- **A2 — Stacked mini-tiles**: small metric tiles (value over label) in a row, similar to StatsPage `ds3-hero` but at smaller scale. Border-top accent strip to tie to Cook Log card.
- **A3 — Heading-inline pills**: compact stone-100 badges next to the 'Cook Log' h3 title, like `ds3-group-badge` pills in StatsPage group headers. Version breakdown wraps to second line.

## Decision B: Dashboard calories tile placement

Render 3+ options for how 'Calories Created' fits into the existing StatsPage hero:

- **B1 — 5th tile**: 5-column grid, add 'Calories Created' alongside Sessions/Items/Recipes/Servings. Mobile wraps to 2-col.
- **B2 — Replace 'Recipes' tile**: keep 4-col grid, swap 'Recipes' (recipe-with-bakes count) for 'Calories Created'.
- **B3 — Second row**: first row keeps the existing 4 tiles, second row adds 'Calories Created' as a wider accent tile.

## Data sources

Render all options against realistic sample data from two recipes:

- **simple-sourdough** — many bakes, has nutrition block, `servingsPerItem === 1` (servings slot hidden)
- **atk-cinnamon-buns-ultimate** — multiple bakes, nutrition block, `servingsPerItem > 1` (servings slot visible), multiple versions (tests version breakdown)

Both should exercise the fallback paths: an entry without `actual_yield` to confirm the `defaultYield` fallback, and the calories `—` placeholder path if a sample variant has no nutrition.
