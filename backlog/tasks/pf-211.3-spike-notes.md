## FDA Nutrition Facts Label Requirements (2026)

Per FDA regulations (21 CFR 101.9), a Nutrition Facts label must include:

### Mandatory Fields (Vertical Order)
1. Serving Size
2. Servings Per Container
3. **Calories**
4. **Total Fat** (g)
5. **Saturated Fat** (g)
6. **Trans Fat** (g) ❌ MISSING
7. **Cholesterol** (mg) ❌ MISSING
8. **Sodium** (mg)
9. **Total Carbohydrate** (g)
10. **Dietary Fiber** (g)
11. **Total Sugars** (g)
12. **Added Sugars** (g) ❌ MISSING (distinct from total sugars)
13. **Protein** (g)
14. **Vitamin D** (mcg) ❌ MISSING
15. **Calcium** (mg) ❌ MISSING
16. **Iron** (mg) ❌ MISSING
17. **Potassium** (mg) ❌ MISSING

### Notes on Current Schema
- Current `fiber` likely maps to **dietary fiber** (same thing)
- Current `sugar` likely maps to **total sugars** BUT does NOT distinguish **added sugars**
- No micronutrient data (Vitamin D, Calcium, Iron, Potassium)

### Current Schema (8 fields)
```
✅ calories
✅ protein
✅ totalFat
✅ saturatedFat
✅ carbohydrates
✅ sugar (maps to "Total Sugars")
✅ fiber (maps to "Dietary Fiber")

```

### Missing FDA-Required Fields (7 fields)
```
❌ transFat (g) — required on all labels
❌ cholesterol (mg) — required on all labels
❌ addedSugars (g) — required since 2020 FDA update, distinct from total sugars
❌ vitaminD (mcg) — required micronutrient
❌ calcium (mg) — required micronutrient
❌ iron (mg) — required micronutrient
❌ potassium (mg) — required micronutrient
```

### Optional/Voluntary Fields (not implemented, not required)
- Vitamin A (removed from mandatory in 2020)
- Vitamin C (removed from mandatory in 2020)
- Other vitamins/minerals (thiamin, riboflavin, niacin, etc.)

## Schema Diff: Proposed Expansion

To support FDA-compliant labels, the `NutrientTotals` interface must expand:

### Proposed TypeScript Schema
```typescript
export interface NutrientTotals {
  // Existing fields (keep as-is)
  calories: number
  protein: number
  totalFat: number
  saturatedFat: number
  carbohydrates: number
  sugar: number              // rename to totalSugars for clarity?
  fiber: number              // rename to dietaryFiber for clarity?
  sodium: number

  // New required fields
  transFat: number           // grams
  cholesterol: number        // milligrams
  addedSugars: number        // grams (distinct from totalSugars)
  vitaminD: number           // micrograms
  calcium: number            // milligrams
  iron: number               // milligrams
  potassium: number          // milligrams
}
```

### Backward Compatibility Strategy
1. **Make new fields optional** during migration (`transFat?: number`)
2. Default to `0` for trans fat (most recipes have negligible trans fat)
3. Backfill existing recipes progressively
4. UI component: render "Not available" for missing micronutrients

## Data Source Implications

Current recipes use **USDA FoodData Central** as the primary data source. USDA FDC provides:

✅ **Available in USDA FDC:**
- Trans fat
- Cholesterol
- Added sugars (for some entries, not all)
- Vitamin D
- Calcium
- Iron
- Potassium

⚠️ **Challenges:**
- **Added sugars**: Not consistently available in USDA FDC for all ingredient entries. May require manual calculation for recipes using honey, maple syrup, brown sugar, etc.
- **Micronutrients**: Available but often `0` or negligible for refined ingredients (flour, butter, oils). Accuracy depends on ingredient specificity.
