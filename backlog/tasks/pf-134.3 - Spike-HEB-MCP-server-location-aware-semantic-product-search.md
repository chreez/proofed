## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Explore building an MCP server that wraps HEB product data for ingredient price lookups. The server would be a local tool available to Claude during bake sessions.

**Concept:**
- Input: user area code (or zip) → resolves to nearest HEB store
- Product search: semantic query ("butter unsalted 1lb") → matched HEB products with name, brand, size, price
- Output: structured product records for cost snapshot feature (PF-134)

**Research questions:**
1. Can HEB's internal GraphQL API (api-edge.heb-ecom-api.hebdigital-prd.com/graphql) be queried for product search + pricing?
2. What does the store locator endpoint look like? Can we resolve area code → store ID?
3. What auth/headers are needed? Does it work unauthenticated?
4. Can heb.com product search be fetched server-side (search results page)?
5. What's the MCP server architecture? (TypeScript MCP SDK, local server, tool definitions)
6. Rate limiting / anti-bot considerations for personal-use volume?

**Prior art (from PF-134.1):**
- HEB has internal GraphQL API (undocumented, used in COVID vaccine tool)
- Product pages have rich JSON-LD structured data
- No public API or developer program
- Instacart IDP exists but requires partner approval

**Deliverable:** POC MCP server with product search tool, or documented blockers if infeasible.

## Spike Results (2026-02-14)

### Verdict: FEASIBLE — All 3 core APIs work without authentication

### Working Endpoints

**GraphQL:** `https://www.heb.com/graphql`
- Required headers: Content-Type, Origin, Referer, apollographql-client-name/version
- No auth tokens or cookies needed

**1. Store Search** (`searchStoresByAddress`)
- Input: zip code or address + radius
- Returns: sorted list of stores with storeNumber, name, address, distance
- Tested: zip 78745 → 25 Austin-area stores, closest = #428 Brodie Lane (2.07 mi)

**2. Product Search** (`productSearch`)
- Input: search term + storeId (required)
- Returns: products with name, brand, size, price, sale price, availability, images
- `context: \"ONLINE\"` = in-store price; `context: \"CURBSIDE\"` has ~5% markup
- Tested: \"unsalted butter\" at store #428 → H-E-B $3.98, Hill Country Fare $3.28, Central Market $4.48 (sale), Kerrygold $10.48

**3. Category Browse** (`browseCategory`)
- Input: categoryId + storeId
- Returns: products in category with same rich data as search

### MCP Server Architecture
- 3 tools: `heb_store_lookup`, `heb_product_search`, `heb_browse_category`
- TypeScript MCP SDK, stdio transport, local server
- Default zip config, built-in 1 req/sec throttle for WAF

### Risks
- Imperva WAF rate limits after ~15-20 rapid requests (mitigate with throttle)
- No introspection (queries discovered via error probing + prior art)
- Client version header may go stale (extract from HEB build manifest)

### Prior Art
- jtbaker/heb-vaccine-scraper (2021), alfredopzr/heb-scraper (2025), cornflowerblu/strands-agent-shopper (2025)
