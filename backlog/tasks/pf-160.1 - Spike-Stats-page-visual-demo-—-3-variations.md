## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Build a throwaway demo page at `/demo/stats` showing 3 visual variations of the stats tree layout for side-by-side user review. Use hardcoded data from current bake history (no dynamic fetching needed). Variations to explore:\n\n1. **Indented tree** — monospace/terminal aesthetic, `├──` connectors, expandable nodes\n2. **Card grid** — each product group is a card with nested stat rows, more visual\n3. **Dashboard tiles** — hero numbers at top (total bakes, total items), detail tree below\n\nAll three should show the same data: 12 bake sessions, 5 recipes, pizza/sourdough/buns groupings with the three granularity levels. Include the focaccia aberration as a distinct line item.\n\nThis is a design spike — build fast, user picks a winner, then throw away the demo.
<!-- SECTION:DESCRIPTION:END -->
