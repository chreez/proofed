  - 80°F → 75% rise
  - 82°F → 80% rise
- Attribution caption on every variant: "Adapted from The Sourdough Journey V2.0 fermentation chart"

### Three variants rendered side-by-side
- **Variant A — Full grid**: Borders on all cells, sans-serif bold header with stone-100 background, comfortable padding (0.625rem). Classic spreadsheet feel. Mono for numeric column only. Not mobile-adaptive — shrinks in place.
- **Variant B — Bottom borders + zebra**: Minimal. Mono uppercase header with letter-spacing, 2px header underline, 1px bottom borders between rows, subtle zebra striping via `:nth-child(odd)`. Caption above table (editorial prose feel).
- **Variant C — Monospace compact, mobile-adaptive**: All JetBrains Mono. Tight padding. No borders — just rhythm and accent-colored right-aligned numerics. Wrapped in `.vc-scroll` with `overflow-x: auto` and `min-width: 16rem` on the table — this is the explicitly mobile-adaptive variant (horizontal scroll on narrow viewports). Visual cue: 2px left accent border on the scroll wrapper. Lowercase column labels `dough_temp`/`target_rise` to fit the "code table" brand vibe.

### Numeric alignment
All three variants right-align the `rise` column, left-align the `temp` column, per AC #3 / #4.
