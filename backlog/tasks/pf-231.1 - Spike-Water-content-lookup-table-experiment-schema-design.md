## User Decisions (spike review)

- **All ingredients adjustable** — base dough (flour, water, starter, salt) + inclusions + enrichments, not just inclusions. Roles still useful for math (flour = denominator) but UI shows sliders for everything.
- **Freeform additions don't affect hydration** — new ingredients added during experiment don't get water content lookup. Water content for novel ingredients is resolved later by the bake-log agent.
- **Opt-in per recipe** — experiment panel only appears on recipes with explicit `experiment` config block.
- **Show grams alongside %** — derived values display format: "67% (330g)" for hydration, grams alongside inclusion load %.
- **Slider reset: both** — per-slider reset buttons AND a "reset all" button.
- **Collapsed state derived values** — undecided, try during implementation and evaluate in HITL review.
- **Pre-scaled by default** — experiment operates on 1x recipe amounts, scaling applied separately.
