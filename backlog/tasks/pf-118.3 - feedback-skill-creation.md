## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Create a new skill at `.claude/skills/feedback/SKILL.md` that drives interactive recipe review sessions. This is the main deliverable of PF-118.

**Skill flow:**
1. **Recipe selection** — accept recipe ID as argument or prompt user to select from `public/recipes/index.json`
2. **Recipe JSON as source of truth** — agent reads the full recipe JSON before answering any questions. Recipe data is primary authority; external knowledge is secondary and always labeled
3. **Interactive review loop** — user reads through the recipe and reacts:
   - Questions → agent answers from recipe context first, cites external sources if needed
   - Notes → agent records exactly what user said (scribe principles)
   - Flags → agent checks recipe JSON, proposes fix if warranted
   - Agent inferences (tips, technique definitions, sourced suggestions) → presented with accept/dismiss choice
4. **Accept/dismiss per note** — accepted notes persisted as `StateNote` with `source: 'agent'`, dismissed notes discarded
5. **Session conclusion** — version bump proposal (user confirms), changelog entry summarizing all additions/changes, no cook log entry

**Key principles (reference Cook Log Protocol in CLAUDE.md):**
- Agent is a scribe for user input — never embellish or infer unstated details
- Agent-contributed content always distinguishable: `source: 'agent'` in data, visual differentiation in UI (per PF-118.2 outcome)
- Recipe JSON checked before any external knowledge is offered
- Version bump requires explicit user confirmation

**Dependencies:** PF-118.1 (schema — source field must exist) and PF-118.2 (demo — rendering direction must be chosen). Cannot start until both are complete.
