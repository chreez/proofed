## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Hybrid capture: indoor temp via runtime scratchpad prompt, outdoor weather via agent-time Open-Meteo fetch during /bake-log pipeline. Indoor: pre-bake scratchpad reminder fires 'Kitchen temp (°F)?' via useScratchpad.addReminderResponse() with reserved stepId='_pre_bake', flows into bake_stats.bulk_ambient_temps[0]. Outdoor: /bake-log skill fetches Open-Meteo archive API (no key, CORS-friendly) for bake end date + Austin coords, writes weather block directly onto CookLogEntry. Graceful degradation if API down. Technology choice: Open-Meteo over Visual Crossing (no API key, free historical, sufficient accuracy). See PF-185 spike notes for full evaluation.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 CookLogEntry type gains optional `weather` field with shape: `{ location: string, date: string, temp_high_f: number, temp_low_f: number, humidity_avg_percent: number, condition: string, source: "open-meteo" }`
