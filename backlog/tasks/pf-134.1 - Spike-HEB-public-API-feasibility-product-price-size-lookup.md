## Research Findings (2026-02-14)

### HEB Direct API
No public API exists. Internal GraphQL API discovered (api-edge.heb-ecom-api.hebdigital-prd.com/graphql) but undocumented, unversioned, not for third-party use.

### HEB Product Pages (Most Promising)
Product pages contain rich JSON-LD structured data: name, price, size, UPC, brand, unit price. A single fetch of an heb.com URL yields all needed fields. However, HEB ToS prohibits scraping/data mining.

### Third-Party Options
- **Instacart IDP Partner API**: Ideal (real-time product search, pricing for HEB). Requires approval -- uncertain for personal project.
- **Open Food Facts**: Product info but no pricing. Spotty US coverage for store brands.
- **Barcode APIs (Go-UPC, etc.)**: Product lookup by UPC but no store-specific pricing.
- **Enterprise scraping services**: Cost-prohibitive for personal use.

### Recommended Approach (3 tiers)
1. **Manual Entry (MVP)**: User enters product, brand, size, price. Zero risk, always accurate.
2. **URL Paste Enrichment**: User pastes heb.com URL → fetch JSON-LD → pre-fill form. Low risk at personal volume.
3. **Instacart IDP (aspirational)**: Apply for Partner API. If approved, full product search + pricing.

### Sample Data Shape
```typescript
interface IngredientPrice {
  name: string; brand: string; size: string;
  price: number; unitPrice: string; upc: string;
  source: 'manual' | 'heb-url' | 'instacart' | 'receipt';
  sourceUrl?: string; store?: string; datePriced: string;
}
```
