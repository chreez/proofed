## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
First shippable child of PF-256 Bakery Ops Assistant epic. Establishes the shared ProductionPlan localStorage state + /production route + UI mutation. Every later lens (price, labels, schedule, sell, financials, data health) reads from this state. No prices, dates, status, or schedule yet — pure intent capture with provenance.

**Design direction (locked 2026-05-13 via PF-256.2 demo review):** Demo B "Cart" pattern overall — main canvas + sticky right cart sidebar. Click [+] in library row to add to cart. No modal picker. Cart sidebar collapsible.

**Library refinement (locked 2026-05-13 after second HITL pass):** Library shifts from card grid to **dense list with small left thumb** (power-user feel, tasteful image use). Each row: 48-56px thumb + recipe name + yields + category + bake count + [+]. Library has search input + sort dropdown (default = most baked). Keyboard nav: j/k move, Enter adds focused row.

**Deferred for later slices (user-acknowledged trade-offs):**
- Queue reorder — Demo B has no drag-to-reorder; filed as follow-up.
- Hero photo sizing polish — banner thumbs feel large; defer to implementation pass.
- Drag interaction — Demo B is click-to-add only; revisit if needed.
