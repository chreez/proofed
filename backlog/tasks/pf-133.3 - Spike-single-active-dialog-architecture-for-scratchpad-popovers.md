## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Currently each ScratchpadNote popover manages its own isOpen state independently. Multiple popovers could be open simultaneously. Need shared state so only one dialog is active at a time — opening one closes the others (including the GeneralNotesFab panel).

**Options to explore:**
- Shared reactive `activePopoverId` in the scratchpad composable
- Event bus approach (close-all event when any opens)
- Provide/inject from a parent wrapper

Should also consider interaction with TOC sidebar and other overlays.
