Each recipe here is agentically augmented. Each recipe is an experiment of how I am using AI to create while also researching recipes. The website itself is polished to a pretty nice degree and the next step would be to generify the system and figure out how to just "let the system go" for a few hours and see what lands.

"unproofed" vs "unbaked" — better term that aligns with the brand. "proofed." means proven/tested (code) and risen (bread). "unproofed" = not yet proven through baking, not yet risen.

Scope:
- Update index demo terminology (unbaked → unproofed)
- Audit any future references in recipe schema / UI copy
- Consider whether "proofed" status deserves a schema field (e.g. `proofed: true` on recipes that have been baked + validated)
