## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Calling `mcp__bsm__bsm_product_get(handle)` throws: "product.tags.join is not a function".

Root cause: Shopify's /products/{handle}.json returns `tags` as a comma-separated string; /products.json returns an array. `formatProduct()` in bsm-mcp-server/src/api.ts calls `tags.join(", ")` which blows up on the string variant.

Fix:
- Normalize `tags` in formatProduct: if string, split on comma + trim. If array, pass through.
- Add test fixture for /products/{handle}.json shape
- Verify product_get works on heritage-bundle-certified-organic and a regular flour handle

Blocks: PF-275 picker integration if it needs to call product_get for variants/details.

Source: PF-275 grooming session 2026-05-19.
