## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Research spike for PF-149. Answer the key design questions before implementation:

1. **Separate skill vs flag**: `/execute-async` as new skill or `--async` flag on `/execute`?
2. **HITL gate batching**: When 3 tasks are running and 2 hit HITL gates simultaneously, how does the orchestrator batch these for a single user review pass?
3. **Commit conflict resolution**: When parallel tasks touch overlapping files, what's the queue/lock strategy?
4. **Context window budget**: How many concurrent background agents can run before context management becomes a problem?
5. **Failure isolation**: If one background agent fails, how are the others affected?

Output: documented design decisions in task notes, informing PF-149 implementation.
