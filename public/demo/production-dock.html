Tradeoffs

Best for
Always-visible queue context while browsing — never lose sight of what's already added. Horizontal scroll suits long queues.
Worst for
Detailed queue editing (small dock cards). Bottom dock steals vertical real estate from library on shorter laptops.
Mobile fallback
Dock unpins, library hides; queue becomes a stacked review list. No drag, no compose — read-only review mode.
