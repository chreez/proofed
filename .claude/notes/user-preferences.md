# User Preferences (Steering Rules)

## Equipment Preferences

### Stand Mixer
- **Preferred**: User enjoys using stand mixer for ease of use
- **Vessel optimization**: Use mixer bowl as primary vessel for dough ingredients to reduce vessel count
- **Workflow**: Measure dry ingredients directly into mixer bowl when possible

## Recipe Authoring Rules

When creating recipes that support stand mixer:
1. Design workflow around mixer bowl as primary vessel
2. Minimize separate measuring bowls — weigh ingredients directly into mixer bowl when order allows
3. Note hand-mix alternatives for users without mixers
4. Include mixer speed and timing cues (low, medium, duration)
